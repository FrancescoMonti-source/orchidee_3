À propos de l'audit v2, glossaire SIL & contrôles d'intégrité (ADR-0003)

Objectif : vérifier individuellement les 8 462 libellés bruts (champ NATUREPVT dans GLIMS) pour construire l'adaptateur local du CHU de Rouen selon les référentiels ONERBA et SPARES. Aucun identifiant (PATID, EVTID, ELTID) n'est présent dans ce fichier.

Glossaire rapide : SIL = Système d'Information de Laboratoire (GLIMS) · TYPEANA = code d'analyse prescrite (ex. BGSTRB dépistage Strepto B, BGSTA_R dépistage SARM, BGCULTAE culture aérobie, BGFA* flacon hémoculture, BGUCYTO/BGASPU ECBU, BGNUML/BGEDL liquides stériles, _R dépistage BMR/BHRe) · *_MY = panel antifongique de mycologie · SEJUF / SEJUM = unité fonctionnelle / médicale · TRI = discipline de tri laboratoire.
